# STILL HUMAN · 玩家记录

玩家对白、NPC 主动开场、当时真实身份及处决／过夜／结局节点的静态探索报告。

## 打开

- 在线入口：https://wwweiweihank.github.io/play_record/
- 本地包：下载 `STILL-HUMAN-play-record-20261001.zip`，完整解压后双击 `index.html`，或运行 `打开报告.cmd`。
- 支持 Edge、Chrome 等启用 JavaScript 的浏览器。本地使用无需 Node、Python、服务器或网络；不要在禁用脚本的文件预览器中操作。

## 游玩时长与漏斗

打开「游玩漏斗」查看玩家累计平均／中位观察时长、每局均值、有起点与结局的均值、时长分布和逐玩家／逐局明细。核心流程与游戏天数推进漏斗可切换局次／匿名玩家，并显示起点比例、上一步转化和未观察到后续数量。

正式快照的玩家累计平均为54.0分钟，中位数30.4分钟；每局平均25.0分钟，16个完整首尾样本平均51.7分钟。核心流程局数41→26→26→26→24→16；玩家数19→17→17→17→16→11。

时长是同会话事件首尾的观察跨度，多会话求和并排除离线间隔，玩家汇总合并同会话重叠区间；暂停／挂机仍可能包含在内，不能当作精确有效游玩时间。上方筛选挑选对局，指标使用所选对局在当前快照中的完整上下文。推进天数是游戏内天数，不是自然日留存；缺少后续不等同于流失。具体口径及样本缺失数在页面内可展开查看。
